# How I add the next case study

When I finish a new project, I open this same Claude Project and give it three things: what problem I was solving, what I actually built to solve it, and what came of it, tests passed, demo given, or feedback received. That is the same three beat shape I used for all four current case studies. The Claude Project already has my voice card, my stack, and my approved bio, so I do not re-explain any of that. I just drop in the new project facts and ask for a new case study block plus an updated portfolio section. Once it is drafted, I paste it into the portfolio HTML file in the same visual style as the existing four, dark background, Space Grotesk headings, Inter body, no AI generated images, only real screenshots.
